Given an array of integers, find the length of the longest increasing subsequence (LIS).

Example: [10, 9, 2, 5, 3, 7, 101, 18]
LIS: [2, 3, 7, 101] or [2, 3, 7, 18], length = 4

Tasks:
1. Design a dynamic programming solution with O(n²) time complexity
2. Explain the approach to optimize it to O(n log n) using binary search
3. Trace through the example step-by-step showing your DP table
4. What is the LIS length for: [0, 1, 0, 3, 2, 3]?
